Claude Code Cocktails

01 — Why

I spent the last couple of months learning Claude Code by building real projects. A few classmates wanted to learn the same way, so I organized a hands-on three-hour workshop with cocktails.

02 — What we did

In my experience, the setup is the hard part. Once GitHub, Vercel, and Claude Code are connected, it’s just as easy as any other vibe-coding tool. So that was the goal for the class: get the setup done, then deploy something by the end. We worked through it together, step by step. Some people rebuilt a portfolio they already had, others just made something for fun.

03 — The result

By the end, everyone had a live URL. A few rebuilt existing portfolios into real sites. Vera made a Dogs vs Cat fight animation just because it was funny, and it’s one of my favorite things that came out of the day.
